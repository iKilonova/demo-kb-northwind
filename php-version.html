Northwind PHP version procedure

Shared accounts default to PHP 8.3. The account holder may switch among 8.2,

8.3, and 8.4 from the control panel under Software, then PHP version.

A change applies to that account only and takes effect within one minute. PHP

8.1 is retired and cannot be selected. Multi-PHP per directory is not offered

on shared plans.

VPS customers install and pin PHP themselves. Northwind does not change the

VPS PHP version on request.
