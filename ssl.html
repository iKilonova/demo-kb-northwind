Northwind TLS certificates

Shared accounts receive a free automatically renewed certificate for the

primary domain and the www name. Extra names need a SAN certificate, which

Northwind issues on request from SSL in the control panel.

Private keys never leave the server. Uploading a customer-supplied certificate

is allowed; the account holder pastes the certificate and chain, never the

key, because the key is generated on the server.

VPS customers install certificates themselves.
